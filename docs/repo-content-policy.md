# Repository content policy

This repository intentionally excludes:

- original or inherited project source code
- third-party example characters and model sheets
- copyrighted music, lyrics, and final videos
- frame sequences and large render outputs
- browser profiles, caches, dependencies, and local history
- author biographies, promotional text, upstream repository links, and unrelated identity information

Allowed content:

- newly written methodology documents
- reusable prompt text
- QA workflow and checklists
- a small number of original QA images that do not disclose private data

If source code is added later, its actual license obligations must be reviewed before publication.
